# 重量尺寸变更记录修复验证

完成时间：2026-09-26 03:07:46（北京时间）。

## 原因与修复

- `list_orders` 使用临时表，但 DBUtils 在达到 maxusage 后可在语句之间更换物理连接，使临时表丢失。真实重拉出现 MySQL 1146。查询开始前显式 `begin()`，固定会话；close 时连接池回滚并归还。
- `_run_changed_read` 调用了另一个函数局部作用域中的 `save_completed`，该名称在当前作用域不存在。改为成功记录每 100 条批量保存，并捕获后台异常、将任务置为 failed，避免一直停留在 querying。
- 删除上传流程中未使用的局部保存函数及队列；原有上传保存和去重逻辑保留。
