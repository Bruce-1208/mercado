# 泽顺插件

适用于 Chrome 和 Edge 的 Manifest V3 扩展。在 Mercado Libre、1688 或智赢产品页使用
“采集到泽顺”，或在搜索列表的商品卡片点击“采集”，商品会写入武汉泽顺综合
服务台的“商品采集”列表；还可读取采购平台登录态并回填物流号。

## 功能

- “美客多采集”支持选择已打开的 Mercado Libre 列表页，设置采集数量（1–500，默认 20）、缓和模式（单进程）或普通模式（默认 5 个进程），并设置销量上下限；
- “Yandex采集”可输入关键词和数量，复用 Yandex 控制台现有的国外商品采集器；插件显示任务进度和结果入口，关闭悬浮窗后任务继续在服务端执行；
- 输入关键词并选择国家时，固定打开对应国家的 Internacional 国际卖家专区；支持墨西哥、巴西、阿根廷、智利、哥伦比亚和乌拉圭；
- 客户只需登录泽顺；管理员在泽顺服务端配置商品数据源，无需客户安装或登录智赢插件；
- 批量任务每件都从泽顺后台读取销量与发货方式，只放行自发货和半托管；海外仓、本土仓、全托管及未识别商品全部跳过；
- 点击扩展图标会打开独立悬浮小窗；点击网页或切换标签页不会自动关闭，再次点击图标会聚焦已有小窗；
- 在支持的业务网页上显示可拖动的泽顺快捷图标，点击即可打开或聚焦插件悬浮窗；也支持 `Ctrl+Shift+Z` 快捷键；
- 批量任务按实际翻页链接读取列表，在新 Edge 窗口中并发打开商品详情并上传；当前窗口不受影响，关闭悬浮窗后继续运行，可重新打开查看页数、候选、已处理、成功、失败、跳过、耗时和当前商品；
- 支持墨西哥、巴西、阿根廷、智利、哥伦比亚和乌拉圭 Mercado Libre 站点；
- 支持 1688 搜索列表逐商品采集；列表采集会在后台打开对应详情页，并复用核价核重的 SKU/包装数据读取逻辑；详情页采集完整图片、属性、详情、重量和三边尺寸；
- “智赢产品采集”会先打开智赢网页版登录页；登录完成后读取当前网页分类与产品开发，可指定起始产品编号，并设置本次最多处理数量；
- “美客多采集”和“智赢产品采集”可选择“泽顺产品分类”，采集入库时自动归入该分类；智赢的来源分类用于筛选商品，泽顺分类用于指定入库后的归属；
- “智赢查侵权”只读取待审核商品的标题和主图，每 20 个标题交给 DeepSeek；无风险改为通过，有风险改为疑似，写回前会再次确认状态；
- 支持 1688、淘宝 / 天猫、拼多多和闲鱼采购订单物流号同步；
- 物流同步不收集采购平台账号或密码，只使用当前浏览器 Cookie。在插件“订单物流”选择美客多下单日期范围（北京时间，含结束当天）和采购平台并点击“启动并打开采购平台”，无需工作台创建任务；手动登录后点击“确定登录”自动查询日期范围内有采购订单号、没有采购物流号的美客多订单，未找到的跳过。订单页“物流同步日志”保留最近 100 次同步与逐单结果；
- 1688 商品会进入控制台“AI原创产品”的“1688 原始资料”区；执行 AI 后会生成独立的“AI 美客多刊登稿”，包括商品属性、无品牌西/葡标题、全新双语详情和白底主图；只有刊登稿通过类目、重量、净收益和 Mercado 必填属性校验后才允许上架；
- 1688 与 Mercado 商品会采集并保存 SKU 变体；控制台可按规格名和选项生成组合，编辑 SKU、库存、加价、加重和图片，并在 Mercado 刊登时带上变体属性、库存及图片；
- 详情页采集商品编号、链接、标题、原价、币种、图片、描述、规格、包装重量和三边尺寸；
- 美客多重量、尺寸、体积重和预计净收益由泽顺后台提供，不读取智赢页面浮层；
- 列表页国旗和 Internacional 状态只用于辅助诊断；最终是否采集一律以泽顺后台商品数据为准；
- 从泽顺控制台下载插件后会自动使用下载账号登录，无需在插件中再次登录；登录状态 72 小时后失效。也可以在插件设置中登录或切换账号，账号密码不会保存；
- 控制台断开时保存到扩展本地待传队列，每分钟自动重试，也可从弹窗手动重试；
- 模型 Token、邮箱提醒和 Webhook 全部在泽顺控制台“集成与凭证设置”集中管理，并与登录账号绑定；插件不提供凭证输入框；
- 邮箱授权码、Webhook 签名密钥和模型 API Key 不写入浏览器同步存储，也不会出现在任务日志；控制台只向页面返回“已配置”状态；
- 默认连接公网泽顺控制台 `https://wuhanzeshun.com`；本地测试或兼容旧版工作台时可在设置中改为 `http://127.0.0.1:5000`。

### 1.8.21 重量尺寸更新

- 新增“重量尺寸更新”页，可读取控制台最近一次订单查询任务，启动查询成功产品的重量尺寸更新并查看逐条执行日志。
- 同一智赢产品编号只搜索一次；对应多笔订单时，按订单时间采用最新一笔的实测重量和尺寸，并将产品级别改为“重点”。
- 智赢保存并回读确认后，继续更新关联美客多商品重量尺寸，再读取并重新提交当前净收益；记录表保留每一步日志。
- 可从插件直接打开控制台“重量尺寸变更记录”页上传订单文件并查询运单。

### 1.8.22 1688搜图提交修复

- 1688上传图片后即使页面清空或替换文件控件，也会根据“已上传图片”回执、搜图弹层和预览图识别“搜索图片”等提交按钮并触发搜索。

### 1.8.23 Yandex 采集集成

- 在插件“Yandex采集”页填写关键词和采集数量（1–500，默认 200），点击“启动采集”。插件使用当前泽顺账号启动现有 Yandex 搜索任务，并保存任务编号；关闭并重新打开插件仍可查看已找到、已检查和完成状态。
- 点击“打开采集结果”会打开泽顺控制台的 Yandex 商品结果页，继续查看商品资料和执行原有的上架流程。打开网页结果页需要正常的泽顺控制台网页登录状态。
- Yandex 采集在运行泽顺控制台的电脑上执行；该电脑需已安装 `yandex` 运行环境和 Chromium。遇到 Yandex 验证码时，按 Yandex 控制台的提示处理。

## 安装

1. 登录泽顺控制台，在“商品采集”或“AI原创产品”页点击“下载泽顺插件”。下载包会自动绑定当前控制台账号，插件安装后无需再次登录；插件登录状态 72 小时后失效。
2. 将下载的 ZIP 解压到一个固定文件夹（不要直接在压缩软件中打开）。Chrome 打开 `chrome://extensions/`；Edge 打开 `edge://extensions/`。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择打开后直接能看到 `manifest.json` 的文件夹。新版 ZIP 根目录直接包含该文件；如果是旧包，请进入内层 `zeshun_collector` 文件夹。拖入扩展管理页无反应时，请使用“加载已解压的扩展程序”选择上述目录，安装后不要移动或删除该目录。
5. 点击插件图标打开悬浮窗，插件会显示下载时绑定的泽顺账号；如需更换账号，可在“设置”中手动登录。模型 Token、邮箱和 Webhook 请在控制台“集成设置”中保存。
6. 打开 Mercado Libre 或 1688 商品详情页，点击页面右侧“采集到泽顺”；Mercado 和 1688 搜索列表页也可点击商品卡片上的“采集”。
7. 批量采集智赢产品时，切换到“智赢产品采集”，插件会自动打开 `meli.zying.net` 网页版；完成登录后重新打开插件，点击“读取当前网页分类与开发”，选择分类，可选填起始产品编号，并设置最多产品数。
8. 同步采购物流号时，直接打开插件“订单物流”，选择美客多下单日期范围（北京时间，含结束当天）和采购平台并点击“启动并打开采购平台”；完成登录后点击“确定登录并开始同步”。自动处理日期范围内有采购订单号、没有采购物流号的美客多订单，未找到的跳过；在泽顺订单页点击“物流同步日志”查看历史及逐单结果。

更新到 1.4.2 后，请重启本机控制台，在扩展管理页重新加载插件，并刷新已打开的智赢产品页。产品分类显示名称，内部编码仅用于筛选；名称未读取完整时会提示待同步，请等待智赢产品页加载完成，再点击“读取当前网页分类与开发”。

### 智赢分类与产品开发读取提速

读取时优先使用智赢页面已加载的分类和人员选项；没有人员控件数据时，浏览器缓存读取共用 800 毫秒预算，旧版页面接口共用 1.2 秒预算。分类只读取一次，网页数据读取后立即显示。后台补全最多等待 2.5 秒，暂时不可用时保留已读取的筛选项；补全期间保留原人员选择并锁定启动按钮，避免范围被意外改成全部。

服务器选项接口由 Web 服务直接处理，缺少人员时仅补充已有缓存或历史人员，不再启动额外浏览器查询。采集任务的启动、状态和停止仍由后台任务服务执行。需重新加载插件，并让 Web 服务加载更新的代码；若启动任务仍提示后台服务不可用，请检查后台任务服务状态。

### 1.5.2 美客多采集

在“美客多采集”中输入关键词、选择国家并点击“打开该国 Internacional 前台页”。页面加载完成后重新打开插件，选择该列表页；插件检查当前页面中的智赢插件登录状态。检查通过后填写采集数量并选择采集模式，再启动批量采集。普通模式默认使用 5 个采集进程，缓和模式使用 1 个。

任务创建的搜索地址及每一条翻页地址都会尝试带上 Internacional 条件。最终筛选以 1.5.4 起的智赢销量和发货方式终审为准；页面未真正进入 Internacional 也不会放宽规则或误采。采集数量是希望成功采集的符合条件商品数，达到数量或搜索末页即结束。

### 1.5.3 并发标签页修复

1.5.3 解决了轮询时频繁闪切标签页的问题。1.5.4 为了保证智赢数据必定被渲染，会对每个详情页仅激活一次并串行读取，上传仍可并发；不再允许缺少智赢数据的 Mercado 商品以 `partial` 状态入库。

### 1.5.4 智赢销量与发货方式终审

销量筛选的数值从智赢插件读取。每个详情页都要等到智赢商品信息，不再在智赢未注入时作为 `partial` 商品入库。只采集智赢确认的自发货和半托管；海外仓、本土仓、全托管或发货方式未识别时不采集。即使 Mercado Libre 的 Internacional 按钮/地址条件没有真正生效，任务也会继续翻页并逐件用智赢信息做严格筛选。

### 1.5.5 异常通知

在泽顺控制台“集成与凭证设置”中可配置 SMTP 邮箱提醒和 Webhook。启用后，插件遇到访问限频、滑块或验证码、Mercado 买家账号登录、采购平台账号登录以及核重核价暂停等待人工处理时，会通过已启用的渠道发送告警。同一来源和相同原因 30 分钟内只发送一次。

### 1.6.0 智赢产品查侵权

插件新增“智赢查侵权”页。登录智赢并读取当前网页筛选项后，可按产品分类、产品开发、起始产品编号和最多产品数运行。任务只查询“待审核”商品，只保留产品编号、标题和主图；标题固定每 20 个提交给 DeepSeek。未发现风险的商品改为“通过”，发现风险的商品改为“疑似”。每次保存前会按产品编号再次确认仍处于“待审核”，状态已被其他人修改的商品会跳过，不会覆盖。

AI 原创产品的文本模型和图片模型分开配置。图片模型需要支持 OpenAI 兼容的
`/images/edits` 接口；不配置图片模型时只允许生成本地白底处理稿，不能通过最终的
Mercado 直接上架校验。

### 1.7.1 挂机任务暂停告警

- AI 核重核价暂停超过 10 分钟后才发送邮件提醒。
- 同一次暂停只尝试发送一次，恢复后才会为下一次暂停重置。
- 智赢翻页慢时先等待列表刷新；超时改为保留进度的可恢复暂停。

### 1.7.2 核重核价后台执行

- 核重核价的自动采集、搜图、识别与回填默认在后台标签页执行，不再反复切换 Edge 标签页或抢占当前焦点。
- 只有主动打开登录页，或任务遇到登录失效、验证码、人机审核等必须人工处理的情况时，才会显示对应页面。

### 1.7.0 悬浮窗与集中凭证设置

点击扩展图标后不再使用失焦即关闭的工具栏 popup，而是创建可持续停留的独立小窗；重复点击只会聚焦已有窗口。插件自身不配置 Token；它会按当前登录账号读取控制台集中保存的凭证。插件直接使用的第三方模型 API 有两项：

- DeepSeek OpenAI 兼容 API（默认 `https://api.deepseek.com`），用于“智赢查侵权”；
- 阿里云百炼 OpenAI 兼容 API（默认 `https://dashscope.aliyuncs.com/compatible-mode/v1`），用于“AI 核重核价”的 Qwen3-VL。

商品采集、智赢产品采集和订单物流使用网页现有登录态，不需要额外 API Key。Mercado Libre 店铺 Access Token / Refresh Token 仍由控制台服务端管理，不能配置到浏览器插件中。

控制台“集成与凭证设置”还统一管理 AI 原创图片所需的 OpenAI API Key、AI 视频所需的火山方舟 Seedance Key 与阿里云 Wan Key/Workspace ID，以及 SMTP 和 Webhook。页面提供功能—模型—Token 对照和各服务的简易配置教程。

插件使用 `/api/browser-extension/login` 校验泽顺账号，并使用签名的短期令牌调用
`/api/browser-extension/collect`。插件不会绕过控制台登录，也不会在浏览器中保存密码。
如果当前运行的控制台尚未重启、上述接口返回 404，插件会自动使用已有的
`/api/login` 验证同一账号并进入兼容模式，无需为此重启正在使用的控制台。兼容
模式仅用于插件与控制台在同一台电脑的情况；跨电脑连接仍需重启控制台加载新版接口。

### 1.8.0 页面快捷入口与键盘快捷键

在泽顺支持的业务网页上会显示一个始终可见的泽顺图标。拖动图标即可调整位置，位置会保存在当前浏览器中；点击图标会打开或聚焦插件独立悬浮窗。浏览器工具栏中的扩展图标仍然可以执行同样的打开操作。

插件还注册了 `Ctrl+Shift+Z`（macOS 为 `Command+Shift+Z`）快捷键，可在任意普通网页中直接打开插件。若该组合键与浏览器或其他扩展冲突，可进入 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 自定义。

### 1.8.1 智赢 5.1.18 采集兼容

智赢 5.1.18 起将 Mercado 商品详情数据放入封闭 Shadow DOM。泽顺插件改用 Chromium 扩展专用的 `chrome.dom.openOrClosedShadowRoot()` 读取该区域，不修改网页的 `attachShadow`，避免触发智赢的防篡改保护。批量采集现在可以继续读取智赢销量、发货方式、重量、尺寸和仓库国家。

### 1.8.2 智赢保护文字与净收益修复

智赢 5.1.18 的重量、尺寸和净收益不再以普通 DOM 文字显示，而是写入随机 `blob:` SVG 背景图，并在文本层加入噪声。泽顺插件现在会从受保护显示层解码真实 SVG 文字；重量或三边包装尺寸未完整读取时继续等待，不再把半成品上传。完整商品入库后立即唤醒佣金、运费和净收益补算线程。

### 1.8.13 子框架搜图与版本同步修复

1688图片搜索现在会检查页面子框架，并在复用旧标签页时先刷新到当前插件版本，避免旧内容脚本与新脚本并行导致上传后不点击。扩展默认连接公网泽顺控制台 `https://wuhanzeshun.com`，本地测试时可在设置中改为 `http://127.0.0.1:5000`。

### 1.8.15 智赢商品主图 CDN 兼容修复

智赢美客多版商品主图实际可能来自 `http2.mlstatic.com`，历史 1688 采集记录也可能来自 `*.alicdn.com`。插件和本机图片代理现在允许这两个受信 CDN，与 `*.hzzying.com` 一起转换为可上传到 1688 的图片数据，避免误报“智赢商品主图地址不受支持”。

1688 以图搜货跳转到新的结果页后，结果轮询改为注入当前版本脚本并继续等待，不再反复刷新结果页导致“主图上传后未返回结果”超时。

### 1.8.16 1688弹窗搜图点击修复

1688 首页的图片上传框和已选图片弹层由不同页面容器渲染时，插件会依据已选图片和弹层预览定位唯一的搜图按钮；兼容新版以 `div` 和 `searchBtn` 样式实现的提交控件，避免主图上传后只显示搜索按钮却没有触发。

### 1.8.20 1688图片上传入口修复

核重核价上传主图前先打开配置的图片搜索入口，未配置时识别“以图搜款”等入口；即使页面已经挂载隐藏文件控件，也不再跳过入口。打开后重新定位上传控件，避免把主图传给旧占位节点。文件赋值后未出现可执行搜索动作时，不再误报“主图已上传”。新增四项浏览器模拟回归覆盖预置隐藏输入框及延迟挂载；真实1688上传仍需在更新插件后验收。

### 1.8.19 1688已上传图片弹层搜索修复

- 按“以图搜款 / 已上传N张图 / 预览图”的局部弹层识别执行搜索按钮，支持上传后清空、替换或移除文件输入框及网络图片预览。
- 合并按钮和内部文字节点的重复候选，避免将一个按钮误判为多个；不向包含首页关键词输入框的区域扩展识别。
- 搜索按钮等待时间由 5 秒增至 15 秒。

### 1.8.18 1688连接恢复与以图搜款入口修复

- 页面接收端缺失时按超时时间重新注入当前框架，避免页面切换丢失刚注入的脚本；不再由无权限的子框架阻断主页面注入。
- 搜索触发跳转而关闭消息通道时直接检查结果，不重复上传。新页面没有脚本时直接注入，不额外刷新首页。
- 支持新版首页“以图搜款”文字入口及普通 div/span 控件，并等待异步加载的上传入口。

### 1.8.17 1688搜索执行与智赢登录提速

搜图按钮定位现在会遍历选中图片预览弹层内无固定标签或样式的普通 `div`，并将其加入实际点击候选；点击时发送完整的指针和鼠标事件。核重核价的“打开智赢登录页面”不再等待工作台状态接口返回，打开标签页后异步记录登录状态。

### 1.8.14 智赢分类与产品开发筛选执行修复

AI核重核价启动前会在智赢商品页实际切换所选分类和产品开发，并点击对应查询按钮，等待列表刷新后再逐件读取。任一筛选控件无法确认时会停止任务并提示原因，避免把全部商品误当成筛选结果。

### 1.8.12 智赢筛选与1688搜图执行修复

智赢产品采集启动时会同时提交所选分类和产品开发，并在详情补全后再次核对分类编号与产品开发编号；即使智赢列表接口忽略筛选参数，也不会把其他分类或其他开发者的商品入库。

1688主图上传后会等待并执行图片搜索控件，兼容按钮、链接和带 `data-spm-click` 的图片搜索操作。普通首页关键词“搜索”只有在出现图片预览或图片弹窗后才允许执行；找不到明确的图片搜索动作会直接报错，不再默默进入超时等待。

### 1.8.11 1688 逐件搜图修复

修复1688页面的采购物流监听器误抢核重核价消息，导致以图搜货直接返回“未知采购物流操作”的问题。无关消息现在不会回复，核重核价消息会交给1688搜图处理器。

本地插件的1688搜图流程恢复与原Playwright版本一致：在1688首页打开以图搜货，上传当前商品主图，只点击图片搜索区域的提交按钮，等待图片结果页，再逐件打开匹配详情并回填。兼容搜图结果在当前标签页跳转、新建结果标签页，以及新版无链接结果卡片三种页面行为；页面跳转造成消息通道关闭时会继续追踪真实结果页，不再误判失败。

逐件闭环和1688搜图各完成连续20件自动化验证，并通过插件与服务端相关测试套件。

### 1.8.10 严格逐件核重核价

核重核价恢复严格逐件闭环：每次只从智赢读取一件商品，完成1688以图搜货、详情核重核价和智赢回填确认后，才重新读取下一件。回填后待审核列表发生位移时会从所选范围重新扫描并跳过已处理编号，避免漏掉紧随其后的商品；未回填测试模式也不会重复处理同一件。

插件更新后复用旧1688或智赢标签页时，如果页面还没有新版内容脚本，后台会自动注入并重试，修复 `Could not establish connection. Receiving end does not exist.`。

### 1.8.9 核重核价主图与开发人员修复

核重核价读取智赢 OSS 主图时增加扩展访问权限；浏览器直接读取失败时，改由已登录的泽顺服务端安全代理获取，避免任务在搜索阶段以 `Failed to fetch` 结束。

适配智赢当前 Vite 页面：优先从页面的 localForage `logins.select` 缓存读取产品开发人员，并保留旧版页面控件和 webpack 接口兼容。当前网页暂未返回人员目录时，服务端不再尝试启动本机 Edge或阻断分类刷新，而是返回历史智赢快照中的人员并给出提示。

### 1.8.8 1688 商品字段与规格读取修复

修复新版1688页面把公司名作为商品标题、页面图标/推荐图片作为主图、会员年限作为价格、页面普通数字作为克数的问题。标题、主图、价格改为商品专属区域和SKU数据取值；未完成加载时等待，缺少标题/主图或新版规格时停止采集。

后台通过 MAIN 环境只读当前商品的React规格/包装模块，解决内容脚本隔离环境读不到规格的问题。价格、库存、重量与尺寸按SKU编号关联，支持kg/g、mm/cm/m单位换算；不同规格的重量尺寸保留在各规格内，商品汇总只显示一致值。无法确认的数据留空。搜索结果点击时重新读取当前卡片，并核对详情跳转后的商品编号。

1688详情增加规格重量和尺寸展示。重新采集时，未知重量尺寸覆盖旧采集值，避免保留历史误读。旧错误记录需要使用新版插件重新采集。商品存储修复涉及 `erp/mercadolibre_collection_store.py`，运行中的服务需加载更新代码后生效。

### 1.8.7 智赢读取修复

智赢产品采集和查侵权共用的读取入口现在优先选择商品页，必要时进入商品列表，并等待分类加载后再读取开发人员。产品开发优先读取当前网页的控件选项，兼容旧版网页接口；手动刷新跳过前后端旧缓存，核重核价读取不到人员时使用已有服务端接口补全。

核重核价等待商品卡片加载。卡片未显示编号时，逐件关闭旧详情、打开目标详情，并核对标题或主图后读取稳定编号；不再把供应商链接或其他卡片的编号当成商品编号。详情不匹配时明确报错，不提交错误商品。起始页切换失败时不再将当前页冒充目标页。

升级需重新加载 1.8.7 插件并刷新已打开的智赢网页。后端缓存修复涉及 `bit/bit_interface.py` 和 `bit/bit_zying_caiji.py`，服务进程需加载更新后代码才能生效。

### 1.8.6 默认回写与产品开发筛选

### 1.8.5 核重核价持久化回读与后台执行修复

自动核重核价默认在后台标签页运行，不再切换用户当前窗口。页面加载同时监听事件并主动轮询，避免加载完成事件竞争导致误报超时；只有手动点击登录按钮时才主动显示对应页面。

智赢回写现在必须精确定位原商品、确认当前状态为“待审核”、找到并填写重量和净收益、切换目标审核状态并点击唯一可用的保存按钮。保存后插件会强制刷新智赢页面，重新打开同一商品，再回读商品编号、重量、净收益和状态；未提交、未持久化或任一字段不一致时任务立即失败，不再把当前表单中的临时值记作成功。模型或浏览器步骤失败也会把整次任务标记为失败。1.8.6 起 ERP 回写关闭时改为允许测试运行，只记录结果而不修改智赢。

### 1.8.4 核重核价登录与分类刷新修复

核重核价打开智赢登录页时不再等待控制台请求；确认登录不再被无关的产品开发人员接口阻塞。刷新分类会等待智赢单页应用真正加载出分类后再同步，并正确识别 `category_id`、`category_name` 和 `category_leaf_name` 字段。

“智赢产品采集”和“智赢查侵权”每次读取前都会重新查找当前浏览器中已打开的智赢页，不再因插件独立小窗缓存旧标签页而把已登录页面跳回登录页；页面读取到的产品开发人员也会直接同步到两个功能的筛选框。

### 1.8.31 泽顺后台商品卡片

美客多列表和详情页显示商品编号、卖家/国家/信誉、发货方式、销量、佣金、品牌、实际重量、包装尺寸、计抛、两种运费、上架时间和预计净收益。未返回的字段显示“—”。客户只需登录泽顺；美客多采集不再检查智赢插件、Cookie或页面浮层。原有“智赢产品采集”等独立功能仍使用其原有登录流程。

数据链路为：泽顺插件 → 已认证的泽顺接口 → 中央数据源会话。列表最多50件合并查询；服务端缓存商品10分钟、缺失记录45秒、运费汇率30分钟，共享SQLite和锁合并重复请求。数据源登录失效、限频时暂停新查询并提示管理员；不清除客户的泽顺登录。缓存有效期内仍可读取已有商品。实际采集的标题、图片、描述和规格仍从客户浏览器的美客多详情页读取，因此详情页自身仍可能触发美客多验证。

预计净收益按所检查智赢版本的默认显示规则计算：美元售价减15%佣金及运费，最低显示3美元，再按汇率换算人民币。它与卡片展示的商品佣金率可能不同，不代表结算或扣除采购成本后的利润。鼠标悬停“估算说明”可查看。售价使用当前页面价格；价格或配置不同会造成与智赢显示不一致。

#### 服务端安装（管理员）

服务器与扩展必须一起升级；仅安装ZIP不能让旧服务器提供新接口。需要Node.js 20+、可写的本机缓存目录，以及管理员现有账户的有效会话。签名适配已检查的智赢5.1.21本地运行文件；不把第三方运行文件或任何账号凭证打进客户安装包。

1. 将管理员提供的智赢插件目录放到服务器私有目录（包含 `assets/js/background.js` 和 `assets/img/static-chunk.png`）。
2. 使用管理员本人正常登录请求的HAR导入会话，命令如下；HAR与输出文件只能存放在服务器私有目录：

   ```sh
   python3 scripts/configure_mercado_product_data.py --session-har /private/query.har --output /private/mercado-session.json
   ```

3. 在服务进程环境中设置：

   ```sh
   ZESHUN_MERCADO_EXTENSION_DIR=/private/zying-ext
   ZESHUN_MERCADO_SESSION_FILE=/private/mercado-session.json
   ZESHUN_MERCADO_NODE=/usr/bin/node
   ZESHUN_MERCADO_CACHE_DIR=/var/lib/zeshun/mercado-product-data
   ```

4. 重启泽顺服务（分离部署时重启worker），再在扩展管理页加载1.8.31。`GET /api/browser-extension/mercado-data/status` 检查是否配置；它不表示上游实时可用。`POST /api/browser-extension/mercado-data/query` 接受 `{"items":[{"sku":"MLM6226808220","price":900}]}`，price是页面本币售价，仅参与运费/收益估算。两个接口都要求泽顺登录。
5. 后台自动保存上游成功响应中的 `refresh_token`，中心服务启动后默认每30分钟调用正常续期接口。若会话被撤销或续期被拒绝，管理员正常重新登录并重新运行导入命令；客户无需登录智赢。此功能尚未验证长期上游稳定性或商业并发容量。

#### 托管服务的持久配置

通过 `python -m bit.workbench_services` 启动的正式服务，也会读取项目私有文件 `.private/mercado-data/service-env.json`。文件只允许上面的五个 `ZESHUN_MERCADO_*` 配置项，显式环境变量优先；不要在其中放账号密码或token，token仍保存在独立0600会话文件中。修改后需重启管理进程及Web/worker子进程。终端中临时设置环境变量不会影响已经运行的服务。

#### 中央会话自动续期

续期在泽顺后台运行，无需客户更新插件或打开智赢页面。正常服务器启动入口 `start_interface_background_services()` 会启动续期线程；web分离进程、客户端模式以及明确禁用后台服务的进程不会启动。自定义WSGI启动方式也需要执行既有后台服务启动入口；仅导入Flask app不会启动续期。

- 默认每30分钟使用现有有效会话调用 `https://seller.zying.net/api/AuthV2/RefreshToken`；`ZESHUN_MERCADO_RENEW_SECONDS` 可配置为300–86400秒。此间隔是本服务策略，无法据此推断智赢实际会话有效期。
- 成功响应的 `refresh_token` 或续期接口返回的新token会原子写入0600私有会话文件，不进入客户响应或日志。文件写入锁与管理员会话导入共用；晚到的旧响应不会覆盖新登录。
- 单进程线程和多进程共享锁避免重复续期；续期状态保存在共享SQLite中，重启后遵守上次成功时间与失败退避时间。
- 商品查询401时只尝试一次正常续期、最多重放一次查询。续期401/403或重放后仍401，会标记“需要管理员登录”，同一会话不再反复续期。
- 网络异常采用递增退避；续期限频至少等待15分钟。不能通过续期绕过验证码、账号封禁、权限限制或已撤销会话。
- `/api/browser-extension/mercado-data/status` 的 `renewal` 返回 `state`、`last_success`、`next_attempt` 等脱敏状态；需要管理员登录时 `ready=false`。无需创建客户可调用的强制续期接口。

已实测主动续期返回新令牌，保存后再查询MLM6226808220成功。此验证证明当前接口支持续期，不代表已验证长时间无人值守或线上部署完成。
