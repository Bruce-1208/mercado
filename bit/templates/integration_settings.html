邮箱提醒

插件遇到登录失效、滑块验证、限频或任务阻塞时，自动发信提醒。

未配置
QQ / 163 / Gmail / Outlook 简易配置
  1. 在邮箱后台开启 SMTP 服务。
  2. 生成“授权码”或“应用专用密码”，不要填写网页登录密码。
  3. 填写发件邮箱、授权码和收件邮箱。QQ/163 通常为 SSL 465；Outlook 通常为 STARTTLS 587。
  4. 先保存，再发送测试邮件。

Webhook

为企业微信机器人、中间服务或未来自动化预留统一事件出口。

未配置
接收与验签教程
  1. 准备一个接收 POST JSON 的 HTTPS 地址并填入。
  2. 可设置签名密钥；泽顺会发送 X-Zeshun-Signature: sha256=…。
  3. 签名原文为 时间戳.JSON原始请求体，使用 HMAC-SHA256。
  4. 服务返回 2xx 即视为成功。保存后可发送测试事件。
