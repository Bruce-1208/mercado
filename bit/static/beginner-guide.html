先确认你的工作范围

核对右上角登录账号。企业管理员负责分配功能与店铺权限；业务员只处理自己有权限的店铺。教程中的入口仍遵循系统权限，未登录时需要先登录。

02

完成首次准备

账号与插件准备

首次使用
  1. 登录并完善个人资料

    使用已开通的泽顺账号登录。在右上角「个人资料」核对姓名和联系方式，需要时修改登录密码；修改密码后重新登录。

  2. 下载并解压泽顺插件

    点击工作台右上角「下载插件」，将 ZIP 解压到固定文件夹，安装后保留该文件夹。

  3. 在 Chrome 或 Edge 中安装

    在浏览器地址栏输入 chrome://extensions 或 edge://extensions，开启「开发者模式」，点击「加载已解压的扩展程序」，选择直接包含 manifest.json 的文件夹。

  4. 登录插件，刷新商品页面

    打开泽顺插件，在插件设置中登录泽顺账号，然后刷新已经打开的美客多或 1688 页面。插件更新后也需要重新加载扩展并刷新商品页。

完成标志插件显示已登录，打开受支持的商品页面后能看到采集入口。
插件、Agent、集成设置分别是什么？

插件用于在浏览器里采集商品及执行支持的浏览器任务。Agent是本机执行端，仅在功能要求选择本机 Agent 时按管理员安排安装，并确认在线。集成设置用于配置模型等服务凭证；使用 AI 功能前先确认对应服务已配置。普通商品采集不需要先配置所有模型。

03

让商品和订单有归属

连接你的店铺

由授权人员操作

先在「店铺授权」查看是否已有目标店铺。已授权的店铺核对状态即可；看不到店铺时，先请管理员检查归属与权限。

  1. 选择开发者应用并打开授权链接

    进入「新增店铺授权」，选择用于本次授权及后续刊登的开发者应用，点击授权链接旁的「打开」，登录对应美客多店铺并同意授权。

  2. 兑换并保存授权

    回到泽顺，填写「自定义店铺名称」，粘贴「TG Code 或完整回调链接」，点击「兑换并保存」。授权码失效或已使用时，重新走一次授权流程。

  3. 核对店铺和工作范围

    在「已授权店铺」中核对名称和授权状态，由有权限的人员检查业务员、分组及站点任务设置。开始任务前再次确认目标店铺与站点。

完成标志目标店铺出现在已授权店铺列表，且对应业务页面可选择该店铺。

04

从一件商品开始

采集第一个商品

选品人员
路径 A · 美客多跟卖

从美客多商品页采集

  1. 打开目标商品详情页，核对标题、图片与规格。
  2. 通过泽顺插件的「采集到泽顺」入口采集，等待成功提示。
  3. 回到「美客多跟卖采集」，找到该商品，检查价格、图片、属性与变体资料。
  4. 补齐缺失内容，选择资料完整的候选商品加入「产品列表」。
打开美客多跟卖采集 ↗
路径 B · 1688 货源

从 1688 商品页采集

  1. 打开目标 1688 商品页，确认货源及规格。
  2. 使用泽顺插件采集，等待成功提示。
  3. 在「1688产品区」检查主图、规格、采购信息及可识别的重量。
  4. 需要原创文案和图片时，再进入「AI原创产品」工作流，生成后人工审核。
打开 1688产品区 ↗
采集成功后，还要检查资料

采集不会直接上架。重点检查价格币种、SKU 规格对应的图片、库存、包装重量与长宽高；采集不到的字段需要补齐。商品资料与风险检查完成后，再进入刊登流程。

完成标志能在对应商品区找到刚采集的商品，且详情与源商品一致。
05

确认无误，再提交

审核与刊登

刊登人员
  1. 在产品列表检查商品资料

    打开商品详情，审核标题、描述、图片、类目及必填属性；有多个规格时逐一检查 SKU、图片和库存。服装等需要尺码表的商品，先准备对应尺码资料。

  2. 核对成本、重量和收益

    检查采购成本、包装重量与尺寸、运费和页面显示的净收益／到手价，注意各字段币种。缺失数据先补全，不把页面中的空值当作零成本。

  3. 选择目标店铺和站点

    先选一件准备好的商品，确认刊登账号、目标站点以及页面要求的刊登参数。检查侵权风险与禁限售情况，处理阻断提示后再提交。

  4. 提交并检查最终结果

    使用「批量上架」提交后，查看「产品上架记录」。任务创建或进入队列只表示已受理；逐项核对最终成功、失败及商品编号。部分失败时先看原因，再处理失败项。

完成标志上架记录中目标商品及站点显示成功，并有可核对的商品编号；再到店铺链接或平台确认。
打开产品列表 ↗查看产品上架记录 ↗侵权检测 ↗
06

跟进订单全流程

处理第一笔订单

运营与仓库
查订单→录采购→跟物流→出库发货
  1. 找到需要处理的订单

    进入「订单管理」，按店铺、日期、订单状态筛选，或搜索订单号。打开订单详情，核对商品、规格、数量和站点；数据缺失时先检查筛选条件及同步结果。

  2. 添加或修改采购单

    在订单详情点击「添加 / 修改采购单」，录入真实采购单号、金额及页面要求的信息。批量操作前核对选中的订单，保存后检查采购记录和成本。

  3. 跟进采购物流与入库

    核对采购物流号及实际到货情况。需要同步采购物流时，按页面要求使用已登录对应采购平台的插件；没有物流号时先确认供应商是否发货。库存相关操作在「库存管理」处理。

  4. 按权限完成出库与面单操作

    核对实物、数量和物流信息，再由对应岗位按页面状态执行「申请出库」或确认操作，并打印美客多面单。发货后继续跟踪平台揽收和交付状态。

订单金额会随数据补全而变化

缺少成本时先补齐采购资料；实际运费在发货后同步，结余也会随之更新。面单打印完成后，仍需跟进实际交接和物流状态。

完成标志采购信息与物流记录匹配实际业务，订单进入正确的下一阶段。
打开订单管理 ↗打开库存管理 ↗

08

遇到问题，按顺序排查

常见问题

看不到功能菜单，或找不到自己的店铺？

先核对当前账号及筛选条件。请管理员检查功能权限、企业、业务员与店铺归属；有查看权限不一定有执行权限。不要为了解决店铺不可见而重复添加授权。

插件已安装，但商品页没有采集按钮？

确认浏览器已启用插件，且插件内已登录泽顺账号；刷新受支持的商品页。刚更新时，在扩展管理页重新加载插件，然后再刷新商品页。仍无入口时，记录页面地址和插件版本供管理员排查。

采集成功，为什么产品列表里没有商品？

先到对应来源区查找：美客多商品进入「美客多跟卖采集」，1688 商品进入「1688产品区」。检查搜索、分类等筛选条件；美客多候选商品需检查资料后加入「产品列表」，不会直接刊登。

商品上架失败，或者只有部分站点成功？

打开「产品上架记录」，查看对应商品和站点的错误。核对店铺授权、类目必填属性、规格图片、库存、价格及重量尺寸；修正后处理失败项。提交超时但结果不明时，先核对记录和平台商品，避免重复提交。

订单没有出现，或采购、物流信息没有更新？

先检查日期、店铺、订单状态和搜索条件，再看同步任务结果。确认店铺授权有效；采购物流需要真实采购单号及对应平台登录态。任务显示失败或需要登录时，处理提示后再同步。

任务一直排队，或提示 Agent 不在线？

检查任务选择的执行端。使用本机 Agent 的任务需要该电脑上的 Agent 已连接且在线；插件任务要确认插件已登录、相关页面可访问。先看状态与日志，再决定是否重试，避免连续重复启动。

AI 功能无法生成，或生成后资料不完整？

先查看具体错误，再到「集成设置」核对对应服务是否配置，检查页面提示的余额或额度。生成完成后仍要核对标题、图片、规格和类目；资料缺失时先补齐，再审核刊登。

需要协助时，提供这 4 项信息

所在功能页面 · 店铺及商品／订单编号 · 出错时间 · 错误提示或已遮挡敏感信息的截图。
