# 员工任务

企业管理员和超级管理员可从工作台侧栏的「员工任务」进入管理页面，填写标题、内容、开始时间、截止时间，并选择本企业有效账号。管理员可以编辑任务和查看完成状态、完成时间及备注。超级管理员默认管理所属企业，也可通过页面 URL 的 `organization_key` 参数选择企业。

业务员在「今日必办 → 我的员工任务」查看分配给自己的任务，保存进展备注并选择未完成或已完成。页面提供进行中 / 逾期、未开始、已完成、全部任务筛选。时间统一使用北京时间。未开始任务不可反馈；逾期未完成任务持续显示。业务员可将已完成任务重新设为未完成。

更换指定业务员会清空原完成状态、完成时间和备注，管理表单有对应提示；其他管理字段的修改保留反馈。每个任务指定一个账号，反馈仅由该账号提交。任务查看和反馈需要现有 `tasks.view` 权限，企业管理入口由明确的企业管理员 / 超级管理员角色控制。

数据保存在服务端 MySQL 的 `workbench_employee_tasks` 表，首次访问自动建表。客户端通过现有 `/api/db/mercado-action-center` 内部接口的 `employee_tasks` 操作访问同一份数据，发布时需同步更新服务端和客户端。企业、操作者和管理角色由登录会话生成，不接受业务请求中的权限覆盖。

验证：`python3 -m pytest tests/test_employee_tasks.py tests/test_bit_access_control.py -q`。新增测试以 SQLite 适配器验证业务数据变更及隔离，未连接生产 MySQL。
