# 店铺链接加载优化（2026-09-27）

本机 MySQL 当前链接 900,627 条。默认总销量分页已有索引，但价格、重量、库存、同步时间和净收益分页缺少匹配的排序索引。优化前价格降序 50 条列表实测 24.754 秒。

新增 5 个覆盖分页字段的复合索引，以 is_current 开头，后接排序字段、sold_quantity、last_synced_at、id（字段去重）。无其他筛选的上述分页显式选择对应索引。升序时次级排序也改为升序，避免主字段 ASC、次级字段 DESC 的混合方向导致全量排序；相同主字段值的商品次序因此会变化，id 仍保证顺序确定。14 天销量的聚合排序逻辑保持原样。

索引已在本机数据库完成构建，Web 服务已重新加载，后台 Worker 保持运行。其他数据库部署会由现有 schema 初始化流程检查和建立缺失索引。

验证：40 项店铺链接与远程删除回归测试通过；12 种排序组合均核对主字段与次级字段顺序、50 条唯一记录。无筛选第一页、每页 50 条的直接后端调用：冷缓存总销量 0.618 秒；其余调用 0.042–0.163 秒；价格降序 0.082 秒，升序 0.098 秒。这是本机数据库/后端耗时，不含浏览器和网络，不代表所有筛选或深页的耗时。

详细结果见 artifacts/store-link-speed-20260927/verified-benchmark.json；核验脚本 verify.py。新增索引占用存储空间并增加同步写入的索引维护成本。
