# 重量尺寸更新修复（2026-09-28）

## 修复内容

- Global 商品更新仅发送四个包装属性的 `id` 和 `value_name`，不再夹带旧的 `values`、`value_struct`、`value_id` 或无关商品属性。
- 官方未提供尺寸时，读取并保留该商品已有尺寸；缺失尺寸时明确报错，不生成替代尺寸。
- 更新后最多回读六次（间隔 0、1、2、4、8、8 秒），数值匹配后才进入净收益重提；已有值相同则跳过重复重量尺寸提交。回读仍不一致时保留“尚未确认”错误，可稍后重试。
- 同名链接逐条处理查询错误。缺少 Global 关联、授权不可用等异常保留在最终汇总中，不再丢弃整组正常链接。
- 重试时清除旧的泽顺失败状态；日志保留 API 的具体错误原因，结束提示区分订单全部成功与未全部完成。
