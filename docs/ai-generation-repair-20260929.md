## 根因与修复

- 枚举契约不一致：校验先要求 value_name，拒绝合法 value_id。现在先用分类枚举补齐规范名称，再校验；未知 ID 仍拒绝。
- 空可选属性与不完整必填项混为一谈：空属性不写入，随后按全部必填标签严格检查。取消 MODEL、COLOR、SIZE、GTIN、包装字段等生成成功豁免。
- 部分 SKU 的必填项不能提升为全商品共有值：逐 SKU 补齐并报告缺失的 SKU；保留已有不同值。
- “常规/默认”只有在每个 SKU 都共有时才可省略；其余维度仍须映射，不能合并 SKU。
- 拆分规格映射会丢掉完整款式组合。真实复测确认灯串不同供电/模式可能映射到相同身份；冲突时切换完整 SKU 规格重新映射，保留价格、库存、SKU ID 和原始快照。
- 完全相同的重复属性去重；同一属性的不同值仍报错。
- 分类搜索加入已搜索词、失败回答、详情和变体上下文，拒绝重复查询，支持最多五轮同义词/实体上位品类搜索；不得强选不匹配分类。
- 数据库现有重量/包装尺寸传入生成上下文；确实缺失的必填数据保留失败，不编造测量值。
