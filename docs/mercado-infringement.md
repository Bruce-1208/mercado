# 美客多侵权检测与知识库

本次变更提供采集列表、产品列表的统一检测入口、持久任务、商品复核及有范围的品牌规则。当前只完成本地代码与离线验证，尚未部署，也未调用真实 AI、迁移真实数据库或执行平台发布。

## 使用流程

采集列表与产品列表的工具栏均有「侵权检测」「检测任务」，每行可检测单件商品或查看结果。独立「侵权检测」页顶部的「列表检测任务中心」可直接查看当前账号的持久任务；下方保留四来源的范围标题检测入口，两类任务分别记录，范围不能混用。

列表检测支持以下三种范围：

| 范围 | 实际处理对象 |
| --- | --- |
| 已选商品 | 当前勾选的商品 ID，服务端核验可访问范围 |
| 当前筛选全部 | 当前筛选结果的所有分页，提交时确定商品集合 |
| 仅未检测 | 当前筛选中的未检测、结果失效、检测失败商品 |

默认复用内容与规则版本仍有效、且覆盖相同检测范围的结果；「重新检测」包含已经有效检测的商品。任务可取消，已经完成的结果保留；失败、取消或服务重启中断后，可重试失败及未完成商品。正在检测的同一商品不会重复启动。任务按当前账号隔离，刷新页面后仍可查看。

选择 `title` 只检查标题及已保存的西语、葡语标题。选择 `title_image` 会读取实际主图，并向视觉模型发送对应图片，识别图形 Logo、角色、包装与文字；它不是只做 OCR。缺图、图片无法读取、响应无法解析或模型调用失败时，记录失败或覆盖未完成，不返回图片低风险结论。

结果区分未检测、排队中、检测中、低风险、疑似、高风险、结果失效与失败。详情保留实际检测范围、原因、命中规则、商品内容版本、知识库版本和历史。0/1/2 表示筛查风险，不表示已经作出法律侵权认定。

## 商品复核与知识库

商品详情中的人工复核只处理当前商品。放行必须填写依据、适用站点、授权凭证及未来有效期；商品内容（包括标题、主图及图片内容版本）变化或放行过期后，原复核失效。历史仅绑定标题的放行不能继续覆盖图片，需要重新复核。提交「知识库线索」只产生待复核证据，不会自动放行品牌。

知识库规则支持品牌别名、站点 ID、类目 ID / 名称、店铺授权 ID及有效期。一个维度内任意一项匹配，不同维度同时满足；限定的维度缺少商品上下文时不命中。新的拦截或放行决定必须填写依据并明确规则范围。历史缺少结构化范围的人工规则继续按全局匹配，界面明确显示「全局品牌规则（历史记录）」；备注中的站点、店铺不会自动缩小范围。

WIPO 品牌自动导入黑名单并参与风险拦截，历史 WIPO 自动记录也会补入黑名单。自动分析、Wikidata 和商品检测提交的线索保持待复核，不参与黑白名单判断。同步可以追加独立证据，不能覆盖人工决定或恢复已删除记录；WIPO 同步的下载与导入进度持久保存，服务重启后自动续跑，详见 [WIPO 品牌同步说明](wipo_sync.md)。人工复核保留原始来源、复核人、前后版本及证据，更新时校验版本，避免覆盖其他人的修改。关联商品区分实际命中规则和旧结果名称候选；后者需重检确认。

## 上架校验

前端与服务端使用一致的发布判断。未检测、失效或失败商品会在发布前补检；疑似、高风险、人工拦截或补检失败保持拦截，有效且适用目标站点的商品放行可继续。补检按已有检测范围执行，尚无范围时默认标题检查，并不会自动宣称图片已经检查。

立即上架、定时上架、失败重试共用服务端校验。准备完成的最终发布草稿还会按目标站点与店铺校验实际输出的西语 / 葡语标题或 `family_name`；重新翻译、重用或重试的草稿不能绕过校验。内容在校验期间变化、最终标题存在风险或检测失败时，不调用平台发布接口。

## 配置与权限

| 配置 / 入口 | 用途 |
| --- | --- |
| `/settings/integrations` | 当前账号的阿里云百炼（DashScope）凭证；列表任务运行时读取，不存入任务参数 |
| `BIT_CHECK_RISK_VISION_MODEL` | `title_image` 使用的视觉模型，默认 `qwen3-vl-plus` |
| `BIT_RISK_VISION_MODEL` | 旧视觉模型配置兼容入口；仅在上面的主配置未设置时使用 |
| `BIT_CHECK_RISK_AI_RETRIES` | AI 结果失败重试次数，默认 1 |
| `MERCADO_INFRINGEMENT_TASK_PATH` | 持久任务 SQLite 文件；默认项目 `.data/infringement-tasks.sqlite3` |

`risk_check.view` 可读取检测结果及自己的任务；`risk_check.execute` 可启动、取消与重试检测；`risk_check.review` 可提交商品复核。`infringement_knowledge.view` 可看知识库、证据历史与授权范围内关联商品；`infringement_knowledge.manage` 可维护品牌规则及提交待复核线索。店铺相关结果继续受账号可访问店铺范围限制。

服务拆分模式将侵权任务端点及列表风险状态读取交给同一个 worker；`combined` 模式使用单个应用实例。任务存储在服务初始化时恢复中断状态，不能让多个独立实例同时管理同一份任务文件。

## 数据升级与验证

现有服务端 `ensure_*` 机制按需创建或补充检测元数据、商品复核、知识库别名 / 范围 / 版本字段，以及独立证据与历史表；保留原字段和数据。部署时服务端数据库账号需具备已有升级机制使用的建表与加列权限。旧结果缺少内容或规则版本时需重检，不把空值当成风险 0。采集转产品、移回采集及关联行同步保留完整检测 / 复核元数据，内容变化后的有效性仍重新判断。

## 企业知识库隔离

侵权知识库按 `organization_key` 在企业内部共享，不按员工个人拆分。普通账号使用登录账号所属企业；平台管理员使用当前选中的企业。前端传入的企业字段不能替普通账号切换归属。

规则、名单统计、分页搜索、同名查重、批量新增、候选线索、复核记录和来源证据均限定在所属企业。品牌名称唯一约束为 `(organization_key, brand_name)`；不同企业可以分别维护同一个品牌。范围中的“企业内通用”仅表示本企业的全部站点、类目和店铺。

数据库首次初始化会添加企业列，并原子替换旧的全局品牌唯一索引。现有历史规则归属 `wuhan-zeshun`，兼容企业别名 `default`，不会复制给其他企业。现有证据和历史通过原有规则 ID 保留归属。上线前需按常规数据库变更流程备份；本次代码修改未执行生产迁移。

自动分析只读取所属企业店铺的数据；无法唯一确定企业的历史店铺名称不参与分析。关联商品只展示可通过店铺授权确认企业归属的记录。异步检测和分析固定使用启动时的企业；上架前检测按目标店铺所属企业加载规则。内部数据库 API 使用受鉴权的企业转发头，Agent 仍以已验证的账号归属为准。

WIPO 设置、凭证、同步历史、日志与任务锁按企业隔离。原企业继续使用原配置文件，其他企业使用独立的 `.org-<organization_key>.sqlite3` 文件；服务重启会恢复这些企业已保存的自动同步配置。

### 擦边品牌提示

侵权知识库支持维护“擦边品牌”，可设置品牌别名、适用站点/类目/店铺和有效期。命中时显示“擦边品牌仅提示，不处理”，不因该品牌提高风险等级或触发拦截；同一商品的其他独立风险及黑名单命中仍正常判断。修改擦边品牌规则后，旧检测结果按知识库版本失效，重新检测后应用新规则。

### 智赢 / 蓝鲸侵权产品采集

侵权知识库 → 侵权产品采集：选择来源，点击“打开网页”，在执行服务所在电脑的可视 Edge 窗口完成登录，再点击“确定已登录，开始读取”。每次启动都需要用户确认，已有登录凭证不会绕过该步骤；尚未登录时会继续等待确认。

- 智赢打开 `https://meli.zying.net/#/goods/tort`（侵权预警），仓储模式固定自发货；查询条件为 `Status=8`、`StockType=1`。
- 蓝鲸打开 `https://xp.lingdongsz.com/#/allItems/infringement`（侵权投诉），使用当前站点，查询条件为 `storeStatusVol=under_review`。品牌缺失时通过官方商品详情补全，详情权限不足会保留产品并显示提示。
- 自动读取当前站点全部分页，保存图片链接、名称、销量、原币价格、品牌、上架日期、子类目、分类路径及其他可用字段。未返回的字段显示“—”，销量与价格的零值保留。重复采集更新同一来源、站点及产品编号的记录；历史样本保留。
- 结果按企业隔离，查看需 `infringement_knowledge.view`，打开、确认、结束需 `infringement_knowledge.manage`。产品样本不直接修改品牌规则。
- `KNOWLEDGE_PRODUCT_COLLECTION_DB` 可指定 SQLite 保存路径，默认 `.data/knowledge-products.sqlite3`。结果持久保存；运行中的浏览器任务在服务重启后需重新启动。
- 分页提前结束、重复页或采集期间总数变化会报告失败并保留已读取数据；手动结束也保留结果。平台登录状态由网页的官方请求客户端使用，凭证不写入产品记录。
