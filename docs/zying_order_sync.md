# 智赢订单同步

Excel 上传：订单管理 → 设置筛选条件 → 智赢订单同步 → 拖拽文件或选择文件 → 上传并同步采购信息。支持 `.xlsx` / `.xlsm`（最大 10 MB、20,000 行）；旧版 `.xls` 需另存为 `.xlsx`。不需要 Agent 或智赢登录，上传接口为 `POST /api/orders/zying-sync/upload`，multipart 字段为 `file`。后台同步沿用当前筛选、账号店铺权限和业务员范围，并记录操作账号，状态及结束任务接口与在线同步共用。关闭弹窗不影响任务，任务存储在订单 worker 内存中；服务重启后需重新上传，已成功回填的数据保留。

表格前 20 行内需包含表头，支持读取多个工作表。订单标识使用“平台订单号”“美客多订单号”“原始订单号”或“订单号”；回填字段支持“采购成本”/“订单成本”/“人民币成本”/“成本”、 “找货订单号”/“采购订单号”/“采购单号”、 “采购物流号”/“采购追踪”/“物流号”/“物流单号”/“运单号”。仅按平台子订单 ID 匹配，只有打包单号的记录跳过，不分摊打包成本。采购字段可缺列或为空，空值保留已有信息；零成本有效。同一订单的多行采购单号和物流号去重合并，重复的订单总成本仅写一次，成本不一致则整单失败。长编号必须保存为文本；超过 15 位的数值编号、公式、无效成本及超长采购字段会显示失败明细并跳过该订单。需要 `order_analysis.execute` 权限，Excel 上传可供有该权限的非 Agent 管理账号使用；在线 Agent 同步仍限企业管理员和超级管理员。

插件版（1.8.60）：在泽顺插件打开“智赢订单同步”，选择美客多下单日期范围（北京时间，结束日期含当天），点击“启动同步并打开智赢”，手动登录后点击“确定登录并开始同步”。插件读取当前浏览器中的智赢订单页，无需 Agent。日期范围内的全部分页订单按当前泽顺账号的店铺权限和业务员范围读取；服务端复用 `AgentSync.step` 与 `parse_purchase` 校验并写入，包含采购单号、物流号和人民币成本，空单号不覆盖已有值。重复结果回传不会重复写入。进度保存在 `.data/zying-extension-sync.sqlite3`，任务状态按账号隔离；插件窗口关闭不终止同步。服务暂时断连后查询未处理订单继续执行；关闭智赢同步标签页会显示失败，可重新启动。点击“结束任务”保留已成功回填的数据，并拦截后续回传。

启动准备（1.8.60）：启动请求保存任务后立即返回并打开智赢，订单在后台准备；可先登录智赢，准备完成后点击确定登录。只按日期、授权店铺和业务员读取 `id`、`order_number`、`pack_id`，每页 2000 单，不加载财务、商品资料和筛选统计。准备期间显示读取进度并支持结束；取消后不再读取下一页，迟到结果不会覆盖后来启动的任务。服务重启或准备连续 10 分钟没有进度时释放旧任务。启动响应丢失时插件读取当前同日期任务恢复，不重放启动请求。

接口：`/api/browser-extension/zying-order-sync/status` 及 `start`、`confirm`、`batch`、`results`、`login_required`、`stop`、`fail`；使用插件 Bearer 登录，查看需要 `order_analysis.view`，操作需要 `order_analysis.execute`。Web 和订单 worker 需同步更新；插件下载打包清单包括新页面脚本、执行脚本和窗口脚本。

订单管理 → 设置筛选条件 → 智赢订单同步 → 选择在线 Agent（默认）→ 按当前筛选同步 → 自动打开所选电脑的 Edge → 登录智赢 → 确定登录。

后台使用订单列表相同的筛选解析、店铺授权范围和分页查询，先读取全部订单，再通过 Playwright 在独立标签页复用智赢订单页面，每批最多搜索 10 单；结果超过一页时自动拆分。详情通过网页已加载的官方请求模块最多 4 单并发读取，模块不可用时回退到逐单点击详情。Agent 每批回传一次结果，服务器逐单校验和写入。关闭弹窗不会终止任务，重新打开可查看进度。Agent 任务与结果保存在任务队列中，Web/worker 重启后仍可查看、确认登录和结束任务；服务器执行的任务保存在 worker 内存中，服务重启后不会恢复。重新执行会覆盖对应采购字段，沿用现有采购操作日志。

- 回填采购订单号（智赢“找货订单号”）、采购物流追踪号，以及订单详情的人民币成本 `order_cost`。
- 多个采购单、物流号去重后以逗号连接；空单号不会清空泽顺已有值。零成本是有效金额。
- 搜索支持泽顺子订单号和打包单号，但写入前必须确认子订单号归属；仅匹配到打包单时不分摊整包成本。
- 未找到或未添加采购的订单跳过；查询等待响应超时（30 秒）也计入跳过并继续：搜索超时跳过本批订单，详情超时仅跳过该订单，保留同批已读取的结果。匹配冲突、金额不可读取等错误逐单展示。登录失效或浏览器关闭等故障仍会终止任务，保留已完成结果。
- 同步连续 10 分钟没有实际进度时，查询状态或再次启动会结束旧任务并释放占用；Agent 心跳不会延长这个进度期限。等待登录使用单独的 16 分钟兜底期限，旧版本无进度时间戳的 Agent 任务从首次查看起计算宽限期。服务器任务点击结束即撤销后续回填权限，旧线程退出不会释放新任务的占用。
- 同一 worker 同时只允许一个同步任务，状态按操作用户隔离；写入需要 `order_analysis.execute`。

执行端须安装项目依赖并可连接浏览器。Agent 模式使用所选电脑的 Edge；服务器模式（仅超级管理员）使用服务器 Edge。两种模式都会自动打开独立登录窗口，Edge 使用 `BIT_ZYING_EDGE_DEBUGGER_ADDRESS`（默认 `127.0.0.1:9222`）。自动开启调试端口，任务结束仅关闭创建的标签页，保留原浏览器。等待登录最多 15 分钟；关闭弹窗后可重新打开确认。没有筛选结果时不打开浏览器。

更新时必须同时更新并重启 Web 和 worker 服务，保证 `/api/orders/zying-sync/start`、`status`、`confirm-login`、`stop` 及 `/api/local-agents/zying-sync/<job_id>` 接口来自同一版本，且均路由到单个 worker。HTML/登录跳转等非 JSON 响应会显示明确的接口异常信息，不再暴露 JSON 解析异常；启动异常返回 JSON 500。

适配依据：智赢 2026-10-08 可访问的订单页面脚本，页面查询 `orders.load`、详情 `order.view`。列表搜索监听网页自身发出的响应；并发详情复用已加载官方模块的 `getFreeStyleApi`，签名和登录状态由智赢网页自身处理，不修改智赢订单。通过导出方法发现官方模块，不固定 Vite 文件名或导出别名；发现超过 5 秒则使用界面读取兜底。

验证：`BIT_RUNTIME_ROLE=client BIT_EXECUTION_TARGET=agent AI_WEIGHT_PRICE_DATA_DIR=/tmp/zying-sync-speed-test BIT_LOCAL_AGENT_HUB_PATH=/tmp/zying-sync-speed-agent-hub.sqlite3 python3 -m pytest -q tests/test_zying_order_sync.py tests/test_zying_order_sync_speed.py`。包括真实 Playwright 浏览器配合本地模拟响应的查询/详情链路、并发上限、响应乱序、超时取消、登录失效及串单拦截；真实账号端到端同步仍需已登录的智赢浏览器验证。

## 执行位置与结束任务

- 默认使用 Agent；请选择在线且支持业务任务的电脑，业务包会按版本自动更新。
- 执行位置和 Agent 电脑选框可随时选择，当前选择用于下一次同步。已有排队或运行任务时会显示提示；若要改用其他执行端，先结束当前任务，再按新选择重新同步。状态刷新不会锁住选框或覆盖新选择。
- 仅 `super_admin` 可以选择服务器 Edge，后端同时验证角色；普通管理员也不能绕过界面直接调用服务器执行接口。
- Agent 只接收授权筛选范围内的订单标识，采集结果由服务器核验后回填，采购日志记录启动任务的账号。
- “结束任务”支持订单准备、排队、等待登录及同步中状态。结束请求立即释放同步占用并隐藏已有任务提示，可按新选择重新同步，无需等待原 Agent 确认。原 Agent 通过心跳接收停止指令，迟到结果不会再回填或恢复旧任务；已经回填的数据保留。旧版本遗留的停止中任务会在查询状态时自动释放。服务器执行时会等待当前浏览器请求返回，再释放本次同步标签页。
- 任务状态、确认登录和结束操作按创建账号隔离；关闭弹窗不会结束任务。

速度优化：每批最多 10 单，正常情况下搜索和结果回传批次数比原来减少一半。详情读取最多 4 单并发，避免逐单打开抽屉；每波请求结束后才启动下一波，每单 30 秒超时并通过官方 HTTP 客户端取消，保留同批成功结果并继续。并发结果逐个核对智赢内部订单号，回传仅保留采购回填需要的根订单标识、人民币成本、采购单号和物流号，减少浏览器与 Agent 的传输量。Agent 复用登录确认及结果回传中的控制状态，省去批次前重复轮询；请求精简响应时只回传进度计数与控制字段，不重复传输累计结果明细。完整结果仍保存在服务器，订单同步弹窗可照常查看；结果溢出时自动拆分查询。

2026-10-08 本地模拟基准：同样的 10 单、每单 105–150 毫秒详情响应，串行界面读取中位数 1.5708 秒，并发读取中位数 0.4722 秒，约 3.33 倍，耗时减少 69.9%。每种模式测量 3 次，结果保存在 `artifacts/zying-order-sync-speed-20261008/benchmark.json`；这是受控模拟数据，实际提速取决于智赢网络响应、搜索及服务器写入耗时。

连接恢复（2026-10-08）：Agent 等待登录及读取控制状态遇到网络超时或 HTTP 502/503/504 时，最多尝试 7 次，退避等待可被结束任务中断。订单结果写入仍不自动重放，避免响应丢失后重复写入采购日志。确认登录会刷新同步标签页以读取其他标签页更新的登录状态；仍在登录页时恢复等待确认，保留当前任务。业务错误会显示具体原因。服务重启期间 Agent 主程序沿用自动重连机制；更新业务逻辑时优先单独重载订单服务，避免中断 Web 心跳。

2026-10-08 启动验证：本地数据库 2026-07-01 至 2026-10-08 的 22,457 单准备耗时约 4.58 秒；完整保留此前任务的 22,453 个订单编号，另有新增 4 单。当前美客多同范围首批 200 单与原完整列表查询的三个编号字段一致。基准保存在 `artifacts/zying-order-startup-20261008/benchmark.json`，真实服务器耗时取决于数据库负载。
