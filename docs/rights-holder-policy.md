# 权利人同名产品处理与店铺操作记录

官方权利人举报记录保存、PPPI 页面权利人快照保存后，自动执行同名产品规则。官方历史迁移记录、已成功解决且不再出现在页面的案件不触发删除；仍在页面出现的权利人商品、申诉失败案件继续处理。

- ERP 产品列表中标题完全相同的产品统一设为 `infringing`（侵权），已设置的产品不重复更新。AI 原创产品已保存的西语、葡语标题也参与匹配。
- 同企业已同步的全部当前店铺链接按完整标题匹配，包含其他店铺和站点。不会使用模糊搜索匹配近似标题；先去除标题两端空格，再区分大小写比较。不同企业的链接不会混入。
- 每条链接在写入前读取平台最新标题与累计销量 `sold_quantity`。销量 **大于 5** 的保留，销量 **0–5** 的使用现有暂停、删除、回读确认流程；销量缺失、非法或标题已变化的保留并说明原因。暂停核验时发现销量或标题变化，会尝试恢复原状态并核验，不继续删除。
- 平台确认删除后才标记本地链接已删除，保留本地历史。处理失败记录为失败或部分成功，下次权利人同步重试；同名产品处理使用进程间锁避免同时执行。

“店铺操作记录”的“操作任务”增加“权利人侵权处理”和“重量尺寸变更”两个筛选项。权利人处理记录包含来源案件、产品原审核状态、产品编号、链接删除/保留结果、最新销量和失败原因；单链接记录支持按所属业务员筛选。

重量尺寸记录保存、执行日志追加、服务中断恢复时同步到操作记录。首次打开操作记录补齐已保存的重量尺寸历史记录及全部执行日志，原页面继续可用。镜像使用持久去重键，重复刷新或重启不会重复写入相同源记录。原执行时间、操作人、业务员、订单、店铺、目标链接及提交重量尺寸保留；旧无时区时间按北京时间解释。历史按事件原时间排序，分页与日期筛选也按同一时间规则处理。

部署需更新代码并重启工作台服务；分离部署需要同时更新 Web 和 worker，保持原店铺操作日志 SQLite 路径一致。数据库保存入口启用后，下一次官方/页面同步开始执行规则；此变更没有执行真实平台删除来验证，验证使用离线模拟。
