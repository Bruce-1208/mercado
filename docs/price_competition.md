# 价格竞争中心

工作台「营销与资金 → 价格竞争中心」和独立地址 `/price-competition` 提供官方价格检测、同币种利润估算与人工确认建议。需要先同步店铺链接；每页 20 件，可逐件检测或检测本页。页面的商品类型筛选仅筛选本页已检测商品。

## 两种数据源

- 普通商品：依据实时商品的 `catalog_listing=false`，读取 `GET /marketplace/benchmarks/items/{item_id}/details`。展示 `suggested_price.amount`，仅在 `applicable_suggestion=true` 且建议价低于当前售价时提供降价建议。404 显示「官方参考价缺失」；403、网络或其他接口失败显示读取失败，不视为缺失。参考价不是全量覆盖。
- Catalog 商品：依据 `catalog_listing=true`，读取 `GET /marketplace/items/{item_id}/price_to_win?caller.id=...&client.id=...`。使用店铺父卖家 ID 和 OAuth 应用 client ID，展示 `price_to_win`、状态、`boosts` 和未参与竞争的 `reason`。获胜、共享首位或尚未参与竞争时不建议降价；目标价为空时不生成建议。
- 类型未返回时显示「类型待核实」，不根据 `catalog_product_id` 猜测类型。普通商品的参考价与 Catalog 的目标价分列保存与展示，不相互回退或混用。

官方依据：[价格参考](https://global-selling.mercadolibre.com/devsite/en_us/user-products-cbt/pricing-reference)、[Catalog 竞争](https://global-selling.mercadolibre.com/devsite/en_us/support-for-integrators/catalog-competition-gs)。Catalog 获胜还涉及配送、分期、免运费和卖家条件，价格建议不能保证未来持续获胜。

## 利润与人工确认

并排展示当前售价、官方参考价、竞争目标价、最低可接受价、调整后预计利润。商品售价和价格信号须同币种且当前价格一致，商品须处于在售状态。

人工核实资料包含每件固定成本合计、按售价计费比例和每件最低利润，全部使用商品售价币种。固定成本包含采购、物流及固定费用，按售价计费比例包含佣金、按售价计算的税费等，避免重复计入。外币费用须先由操作人换算；缺少资料或成本币种不同，不估算利润，也不能确认建议。模型为：

```
预计利润 = 建议价 × (1 − 按售价计费比例 / 100) − 固定成本
最低可接受价 = (固定成本 + 最低利润) / (1 − 按售价计费比例 / 100)
```

最低可接受价向上保留两位小数，建议价向下保留两位小数，并使用未四舍五入的利润校验底线。低于底线的官方目标仍可查看，但无法确认。此估算不是官方净收益报价，费用随价格变化时须重新核实模型。

预览重新读取官方商品和价格信号，有效期 5 分钟；确认须勾选人工核对，并再次读取官方数据。售价、竞争条件或成本变化，权限丢失、预览过期、重复确认均拒绝。成功后记录确认人、时间及价格和成本快照；资料变化后的旧确认标记为历史记录。

**第一版的确认只保存建议核对记录，不向平台提交价格修改。实际改价使用现有店铺链接流程。** 本模块没有自动改价开关、后台调价定时器或平台写接口。后续自动调价需增加最低利润、单次最大降幅、每日次数、冷却时间、活动冲突保护和调价后回读。

## 权限、部署与存储

权限 `price_competition.view` 控制查看；`price_competition.execute` 控制检测、成本核实及确认建议。所有操作使用登录账号的授权店铺范围；客户端传入的店铺权限或确认人不能覆盖登录身份。只可确认本人生成的预览。

记录由中心服务保存至 `.data/price-competition.sqlite3`（可用 `BIT_PRICE_COMPETITION_DB_PATH` 指定）。备份包含此库。服务启动访问模块时自动初始化，不修改现有 MySQL 商品表。数据库 API 客户端通过 `/api/db/price-competition/{action}` 访问中心服务；Web / worker 分离部署时公共接口及内部接口由 worker 处理。

部署后重启工作台；分离部署需重启 Web 和 worker。为需要此模块的角色分配查看和操作权限。

验证使用离线官方响应与隔离数据库，覆盖两种数据源、缺失与失败区分、利润红线、权限、价格变化、确认幂等和桌面 / 手机浏览器交互；未向真实店铺提交改价。
