# 任务模块使用紫鸟店铺

任务模块的「店铺浏览器」选择「紫鸟浏览器」，执行位置选择运行紫鸟的本机 Agent。单轮、循环、混合任务和算法模式均传递该选择；默认仍为比特浏览器。现有企业权限、业务员/店铺组范围和申诉开关继续生效。

## 任务范围

业务员、店铺组和店铺均支持多选，并可在面板中按名称片段搜索（英文不区分大小写，店铺也可搜索昵称）。业务员与店铺组沿用互斥选择；具体店铺与所选业务员或店铺组取交集，不勾选具体店铺表示不额外缩小范围。所有选择仍受当前账号可见店铺及站点申诉开关限制。

进入任务页会独立读取范围选项，不受任务状态轮询影响；读取失败时显示错误，可点击「刷新店铺范围」重试，已有选择会保留。店铺 ID 会传递至 Agent 的单轮、循环、混合和算法任务，紫鸟仍按授权显示名或昵称匹配唯一同名店铺，不使用模糊搜索结果自动执行。

## 执行电脑配置

1. 更新工作台服务和 Agent 业务包。本次不需要更新泽顺浏览器插件。
2. 在运行 Agent 的环境配置 `ZINIAO_COMPANY`、`ZINIAO_USERNAME`、`ZINIAO_PASSWORD`，然后重启 Agent。只在执行电脑保存这些值，不填写到网页任务参数，也不要提交进代码仓库。
3. 使用紫鸟官方 WebDriver HTTP 启动模式，例如 Windows：

   ```text
   "C:\你的紫鸟安装目录\ziniao.exe" --run_type=web_driver --ipc_type=http --port=16851
   ```

   macOS：

   ```sh
   open -a ziniao --args --run_type=web_driver --ipc_type=http --port=16851
   ```

   如紫鸟已按普通模式运行，先自行保存工作并退出，再按上述方式启动。任务不会强制结束紫鸟客户端。自定义端口时同步配置 `ZINIAO_PORT`，接口固定连接本机回环地址。
4. 店铺必须使用 Chrome 内核。优先使用紫鸟内核目录内的 `webdriver` / `webdriver.exe`；没有时安装与店铺内核版本一致的官方驱动，并将其完整路径填入 `ZINIAO_DRIVER_PATH`。不同内核版本应使用各自内置驱动，避免统一覆盖路径导致不匹配。
5. ERP 店铺授权的显示名或昵称应与紫鸟店铺名称对应。允许空格、括号等分隔符差异，但名称必须唯一；多个别名匹配到不同窗口也会拒绝执行。未匹配时不会回退到比特浏览器。

每轮读取一次紫鸟店铺列表，使用 `browserOauth` 启动对应店铺并连接返回的调试端口。窗口 ID 使用独立的 `ziniao:` 前缀，沿用任务锁及任务结束清理；不参与比特浏览器的进程回收。紫鸟 IP 检测页通过后才进入业务页面。连接、驱动或 IP 检测失败会报告错误。

验证使用模拟接口、模拟驱动和离线页面，不发送真实申诉。实际可用性仍需在配置好的紫鸟电脑验收。

接口依据：[紫鸟 WebDriver 文档](https://open.ziniao.com/docSupport?docId=98)、[官方常见问题](https://open.ziniao.com/docSupport?docId=257)。
