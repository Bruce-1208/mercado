# 业务员个人资料

登录后从工作台右上角或支付管理页点击「个人资料」，进入 `/settings/profile`。

业务员可以保存本人的姓名、邮箱、手机号、微信号和部门。姓名单独保存在 `workbench_users.personal_name`；现有 `display_name` 仍是店铺、商品、订阅站点计数和打印扣费使用的业务员标识。旧账号未填写个人姓名时默认显示原业务员名称。登录账号、业务员标识、角色、企业、启用状态和权限不能通过此入口更改。

修改密码需要填写原密码、新密码及确认密码。新密码为 8–128 位且不能与原密码相同，服务端校验原密码并保存加盐哈希；成功后退出当前会话，返回登录页。个人资料及改密入口不受订阅到期限制。

资料读写由当前登录会话确定账号 ID，写入需要页面 CSRF 令牌。客户端通过受内部令牌保护的 `/api/db/workbench/profile` 使用中心数据库，不读取其他账号资料。

部署后重启数据库服务端及 Web 服务，账号表初始化会自动添加可空的 `personal_name` 列。无需迁移既有业务员归属数据。

验证：`python3 -m pytest -q tests/test_workbench_profile.py tests/test_workbench_profile_browser.py`。浏览器测试覆盖桌面、390px 和 320px 页面，以及加载重试、保存失败恢复、密码校验及成功跳转。
