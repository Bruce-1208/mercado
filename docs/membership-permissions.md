# 会员功能与数据权限

按半陪跑／全陪跑服务范围设置三个对外角色。课程、执照办理、陪跑答疑由线下履约；宣传价格不写入现有 ERP 订阅价格。

| 角色 | 功能 | 数据范围 |
| --- | --- | --- |
| 基础会员 `basic_member` | 订单查看、面单打印；个人资料与本人账单 | 仅本企业分配给本人的店铺；无产品库、AI 与人员管理 |
| 高级会员 `premium_member` | 产品库、采集、刊登、AI 原创与视频，以及已有业务运营模块 | 仅本人店铺；可查看企业共享产品，仅能修改本人产品；他人私有产品不可见 |
| 企业管理员 `enterprise_admin` | 本企业业务、人员、角色和店铺配置 | 本企业；不能管理其他企业、修改管理员角色或授予管理员身份 |

平台超级管理员及原有运营、仓库、只读、成员岗位保持兼容。历史 `member` 账号不自动升级或降级；管理员按实际服务合同调整为基础／高级会员。新建账号默认基础会员，公开注册仍需管理员审核激活。

## 执行位置

- `bit/membership_access.py` 定义会员等级上限与基础会员请求白名单。基础会员对新增模块默认拒绝，直接 URL 和 API 请求不能绕过导航隐藏。
- `bit/bit_interface.py` 在会话生成、权限检查、登录校验（含插件）、角色修改、请求入口执行约束。会员的 `own_store_only` 不能关闭，通配权限不能突破等级上限。
- 产品库和 AI 请求对所有角色分别检查 `catalog.*`、`ai_content.*`。其他模块沿用已有操作权限；Agent 和平台执行能力仍遵守现有管理员限制。
- 店铺沿用企业过滤与本人归属检查，产品沿用 `product_access` 的企业、共享／私有与所有者判断。
- 企业管理员可调整本企业业务角色，管理员角色仅平台超级管理员可改；管理员账号创建、修改、重置密码沿用已有限制。
- 数据库初始化在每个企业补充两种会员角色；只有权限列表仍等于历史默认值的企业管理员会补齐人员管理权限，已定制的限制不覆盖。原有运营、只读、成员的未修改默认角色也补齐相应产品权限；自定义或已收紧角色须由管理员显式授予新增权限。

## 服务期限

现有订阅校验继续阻止未开通、到期和超额度账号。图片中全陪跑包含一年的 ERP 使用权，应通过现有订阅管理按合同登记；角色本身不自动创建付费记录或延长期限。“四家店铺”和“45 万件产品库”是服务承诺，不擅自替换现有按站点计费规则，也不代表系统实际已有该数量的产品。

## 离线验收

`tests/test_membership_access.py` 覆盖等级上限、接口拒绝、跨企业／跨店铺访问、共享和私有产品，以及管理员角色保护；`tests/test_membership_access_browser.py` 复用离线真实模板，验证 1440／390 px 的导航、多选、键盘焦点与页面宽度。浏览器请求全部由模拟数据响应，无真实刊登、同步、扣费或消息发送。

运行 `python3 scripts/test_membership_offline.py` 执行上述后端回归：禁用后台服务，并将导入时的 AI 核重核价存储替换为临时 SQLite，业务权限与企业测试继续使用各自模拟数据库。浏览器验证运行 `python3 -m pytest tests/test_membership_access_browser.py -q`。

## 企业信息与业务员名额

企业管理员在“人员与权限”查看本企业名称、标识和业务员已用／总名额。超级管理员可新增企业并调整各企业名额，默认 3 个，允许设为 0。

名额按企业统计启用的非管理员、非仓库账号（含基础／高级会员、旧成员、运营、只读及自定义角色）。停用账号不占名额；重新启用、从豁免角色改为业务员和新增业务员均检查额度。降低额度不能低于已用人数。旧企业自动补充默认值 3，不停用历史账号；已超额企业可编辑现有人员，但不能增加启用人数，需由超级管理员调整额度。

`workbench_organizations.salesperson_limit` 在服务启动的现有数据库初始化流程中迁移。创建和更新账号在同一事务内锁定企业行后核验人数，API 客户端也经由服务端校验。部署时先更新并重启数据库服务，再更新客户端。

新增离线回归：`tests/test_enterprise_salesperson_quota.py`（通过 `scripts/test_membership_offline.py` 运行）与 `tests/test_enterprise_salesperson_quota_browser.py`（1440／1024／390 px 模拟企业信息、名额设置和键盘保存）。
