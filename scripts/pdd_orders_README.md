# 拼多多个人买家订单导出 V2

安装依赖（使用系统已安装的 Microsoft Edge）：

```powershell
python -m pip install playwright openpyxl
python scripts/pdd_orders_v2.py --start 2026-01-01
```

浏览器打开后手动登录，进入“全部订单”，回到终端按回车确认。
默认结束日期是运行当天的北京时间，包含首尾两天。
输出在 `output/pdd_orders/`，包含 Excel 和保留原始数据的 JSON。
Excel 包含“订单”“日期待核对”“导出说明”。没有确定下单日期的订单不会被悄悄丢弃。

## 第二版逐单补全

每行包含：**订单号、状态、实付金额（元）、标题、物流号**，以及下单时间、物流公司、读取说明、缺失字段和原始内容。
用户所说的“欠款”已确认为“订单实付金额”，不使用商品标价、总价或待付款金额替代。

1. 登录并确认后，先慢速读取全部订单列表。
2. 列表停滞提示处输入 c 继续列表，按回车进入详情补全，输入 q 保存退出。
3. 按提示在**同一标签页**手动打开一笔已读取订单的详情，回到终端按回车。
   脚本从真实地址识别详情路由，并核对页面订单号。若该版本页面不在查询参数中提供订单号，脚本会要求重新确认，不会猜测地址。
4. 自动逐单打开详情，校验订单号，读取状态、实付金额和标题，再点击明确的“查看物流”等只读入口。
   可识别的多个包裹标签会依次读取，多个物流号以中文分号分隔。
5. 每单后保存 JSON；Excel 默认每 60 秒刷新，暂停、结束或正常捕获异常时立即保存。
   未获取字段单独注明；待付款、待发货等状态可能本来就没有物流号，不能凭空补齐。

如需只运行列表采集，可加 `--list-only`。旧入口 `pdd_orders.py` 同样使用 V2 逻辑。

在已加载列表内部每屏等待 0.5 秒，靠近列表底部、点击加载更多或滚动不动时等待 6 秒。
详情与物流访问保留原有间隔。单线程读取页面和页面自然请求的 JSON；不会主动调用、重放或破解接口。
订单卡片改用文本节点定位，缓存未变化卡片和日期解析结果，减少重复 DOM 扫描与解析。
已在当前订单详情页时不重复跳转；详情确认在日期范围外的订单不再访问物流页。
`--save-interval 60` 控制 Excel 刷新间隔；设为 0 可恢复每轮写 Excel，速度会下降。
默认 `--max-rounds 0`，不再因旧版的 240 轮上限截断列表。每轮显示已知最早下单日期和目标起始日期。
轮数是滚动次数，不是订单数或接口分页数，一次滚动可能只移动半屏或一屏。
如手动指定正数上限，到达后会保存并标明“列表未完成”，不自动进入详情阶段。
导出说明列出已读取总数、日期范围内/范围外/待核对数量，以及已知最早和最新日期。
读取到某笔早于起始日期的订单也不能单独证明完整性，因此不会仅凭最早日期自动停采。
遇到验证码、403/429 或登录失效，会保存进度并等待手动处理；输入 c 继续，其他输入结束。
自动寻找页面内部的滚动容器；页面仍向下滚动时，不会因五轮没有新增订单就暂停。
连续五轮没有新增订单且滚动位置不前进时才会询问是否继续，这不表示已确认到底。
每轮输出滚动位置、JSON 响应数量和含订单响应数量，帮助区分未触发加载与字段未识别。
可手动滚动或打开详情以补充数据，继续自动读取前请回到“全部订单”列表。
Ctrl+C 或异常会尽量保存当次已读取数据。每次运行独立导出，不会混合其他账号的数据。
读取时不要打开正在更新的 Excel，以免 Windows 锁定文件导致保存失败。

```powershell
python scripts/pdd_orders_v2.py --start 2026-01-01 --interval 10 --max-rounds 0
```

如果自动化连接状态下无法登录，可先用普通 Edge 完成登录并关闭该窗口，再执行采集：

```powershell
python scripts/pdd_orders.py --login-first --start 2026-01-01
```

专用登录资料保存在 `.data/pdd_orders_edge_profile/`，不要分享该目录。
脚本会复用同一专用资料目录的可用 Edge 采集连接，兼容旧版随机调试端口。
新窗口使用浏览器分配的动态端口。启动进程退出码 0 不再被直接判定为启动失败。
如果是普通登录窗口、没有可用采集连接，会提示正常关闭该专用窗口后重试；不需要关闭其他浏览器或删除登录资料。
脚本结束或异常时不再强制结束 Edge。异常日志保存为输出目录中的 `.error.log`，JSON 与 Excel 分别尝试保存，避免 Excel 文件锁掩盖原始错误。
不自动破解验证码、不伪造设备指纹、不使用代理轮换。慢速读取不保证不会触发平台风控。

限制：网站页面和响应结构可能变化。脚本识别明确的订单号与下单日期，不用物流日期推断下单日期。
未知字段留空；响应中的金额单位未核实时不会自动换算，优先读取详情中的“实付”文字。
订单详情入口、物流入口和包裹标签仍取决于实际网页版本；无法匹配时会注明缺失或暂停。
网页可能只开放部分历史订单，因此无新增、到达轮数上限均不能证明“全部订单已导出”。
请核对“导出说明”和“日期待核对”，并与账号订单数量比对；没有完成真实账号端到端验证前不能保证完整。

实现参考：[Playwright CDP](https://playwright.dev/python/docs/api/class-browsertype#browser-type-connect-over-cdp)、
[浏览器响应事件](https://playwright.dev/python/docs/api/class-browsercontext#browser-context-event-response)。
