# 智赢“运费跳高档”官方重量尺寸导出

这个方案使用智赢自带的订单导出文件获取**智赢内部订单号**，然后按订单号查询桌面端订单详情，直接读取“官方重量”后面的重量和尺寸。导出文件不需要包含重量尺寸。脚本不会打开产品或修改智赢数据。

## 操作

1. 在智赢跨境的“订单列表”选择“运费跳高档”，保留所需店铺、日期等筛选。
2. 用智赢自带的“导出”功能导出这些订单的 Excel，记下文件路径。导出文件至少需要有 `id`（智赢内部订单号）列。`编号` 是平台订单号，脚本不会使用它。
3. 保持智赢订单列表打开，运行：

```powershell
python scripts/zying_order_measurements.py --input "C:\路径\导出订单.xlsx" --max-count 50
```

输出默认在 `output/zying_order_measurements_运行时间.xlsx`，每次运行生成新文件，避免把上次结果误认为本次结果。Excel 仅有 `订单号`、`重量（克）`、`尺寸（厘米）` 三列。通过 `--output` 修改文件路径。

读取少量指定订单时不必导出文件：

```powershell
python scripts/zying_order_measurements.py --orders 150743572 --max-count 1
```

需要的 Python 包：`pywinauto`、`pyautogui`、`psutil`、`openpyxl`。运行时不要操作鼠标和键盘；鼠标移到屏幕左上角可停止。

## 遇到异常

- 订单详情中的官方重量尺寸为空、格式无法解析，或同单出现不同测量值时，该订单不会写入 Excel。原因保存在 Excel 旁边的同名 `.jsonl` 日志。
- 脚本查询每个订单后验证页面显示的智赢内部订单号，再读取官方数据。不能唯一定位订单详情时停止，避免把别的订单写入表格。
- 智赢列表为自绘表格，脚本只在精确查询后点击第一行。若实际点击位置有偏差，可调整 `--row-y-offset`，默认 55 像素。脚本不再使用 OCR 扫描订单或翻页。
